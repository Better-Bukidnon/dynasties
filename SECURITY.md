# Security

This is a static site with no logins, forms or user data. If you find a security problem, such as a way to inject script into a page through the data, email volunteer@betterbukidnon.org instead of opening a public issue. We'll reply within a week.

Wrong or harmful content about a person isn't a security issue. Open a [correction issue](https://github.com/Better-Bukidnon/dynasties/issues/new?template=correction.yml) for that, or email us if it's sensitive.
