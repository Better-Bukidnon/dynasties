# Code of Conduct

This project follows the [Better Bukidnon Code of Conduct](https://github.com/Better-Bukidnon/betterbukidnon/blob/main/CODE_OF_CONDUCT.md). Be respectful, welcoming and constructive, and focus on what is best for the people of Bukidnon.

This site is about real people, so three more rules apply here:

- **Discuss sources, not people.** Debate whether a source states a tie, not whether someone deserves to be in office.
- **No speculation or private information.** Don't post rumours, home addresses, phone numbers, or anything about family members who aren't public officials beyond what a published source says.
- **Neutral language.** Being related to another official is not wrongdoing, so don't word issues, pull requests or data as if it were.

Report problems to volunteer@betterbukidnon.org. Maintainers may edit, hide or remove comments, issues and pull requests that break these rules.
